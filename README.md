**SOLMAR HEAT** — an open-world crime game in sun-soaked Solmar Bay: steal cars, outrun the SBPD, and run four story jobs for Lena and Mr. Okafor. Built with Three.js as plain static files; no build step, no network requests at runtime.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Or serve `game/` with any static file server and open `game/index.html`.

## Play

- **WASD** drive / walk, **mouse** camera (click to lock), **E** steal / exit a car, **F** punch, **Shift** sprint, **H** horn, **M** take the next job, **P** pause, **R** reload your save.
- Wanted level 1–5 stars: the SBPD pursues, rams and arrests. Lose the heat or pay the fine.
- Four missions with waypoints, timers and payouts, plus hidden cash stashes. Progress saves automatically (localStorage).
