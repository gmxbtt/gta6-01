# SOLMAR HEAT — Open-World Crime in Solmar Bay

A Three.js open-world crime game set in sun-soaked Solmar Bay. Play Rico Vega: steal cars, a motorcycle and a boat, run five story jobs, dodge the SBPD through roadblocks, and hunt hidden packages across a living city of traffic, pedestrians and neon.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

No build step, no network requests at runtime — just static files under `game/`, with Three.js vendored as a minified build.

## How to play

- **WASD / arrows** — walk and drive, **mouse drag** — look around, **Shift** — sprint
- **E** — steal / enter a car, bike or boat, **F** — punch, **J** — start the next job, **M** — minimap zoom, **Esc** — pause
- Five jobs: Hot Wheels, Bank Run, Pier Pressure, Heat Wave, Harbor Run. Wanted level 1–5 brings SBPD interceptors, foot cops and roadblocks; progress saves to localStorage.
